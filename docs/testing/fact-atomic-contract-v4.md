# Единый контракт атомизации и сверки, редакция4

Рабочий контракт для одновременной нормализации агентских outputs и независимого поиска. Старые зафиксированные версии не переписываются скрыто; изменения имеют aliases и причину.

## Единица

1. Утверждение содержит субъект, самостоятельное отношение/свойство, значение и обязательную временную область. Пять этажей — один факт; число и единица измерения не отдельные факты.
2. Разные свойства конструкции различаются: высота, диаметр, материал, форма крыши. Высота и диаметр104 считаются так же, как ширина и длина120. Повтор общей характеристики и её точное уточнение получает один канонический узел и partial/full mapping.
3. Одно событие с датой, участниками, стоимостью, предметом, причиной и исходом — один узел события. Один конкурс с нулём заявок и перечнем работ не равен восьми событиям. Один обстрел с повреждением стен и сводов не равен четырём событиям попадания/повреждения.
4. Разные события не сливаются по теме: принятие плана, конкурс, контракт, начало работ, завершение работ. Изменённый датированный план также не является выполнением прежнего плана. Декларация стоимости не выдаётся за контракт или оплату.
5. Охранный статус и акт, которым он предоставлен, составляют один узел с правовым основанием. Существенное последующее изменение предмета охраны/границ может быть самостоятельным событием.
6. Архитектурные свойства различных частей остаются самостоятельными. Шесть разных признаков фасада не «один архитектурный пакет». Но несколько родовых прилагательных вроде «высокий/массивный/необычный» без определяемого критерия не увеличивают счёт объективных свойств.
7. Одна организация/название/владелец в записи использования помещения — одно заселение/использование с участниками. Биография её владельца, не связанная с домом, исключается. Отдельное происхождение названия дома допускается как другое отношение.
8. Повторные сообщения об одном неизменном использовании сохраняют временные доказательства в одном узле, а не добавляют факт на каждый год публикации. Реальная смена использования — новое событие.
9. Идентификационные адреса, номерареестра, сведения о наличии фотографии или страницы — metadata. Само наличие документального снимка без нового свойства/события дома не увеличивает содержательный знаменатель.
10. Адрес комплекса не подтверждает автоматически конкретный корпус. Site/complex candidate хранится отдельно, пока footprint/корпус не связан источником. Это относится одинаково к model output и independent discovery.

## Статусы и покрытие

- verified: источник поддерживает нормализованное утверждение в данномscope/time.
- qualified: существенная атрибуция/время/конфликт требует уточнения.
- unverified: поддержки недостаточно, положительного опровержения нет.
- false: есть положительное противоречие; отсутствие доказательства не ложность.
- excluded: metadata, другой объект/участок/организация, оценка, не содержательный факт.
- dedup: повтор уже учтённого канонического утверждения; исходный verdict сохраняется.

Verified partial match не выдаётся за full coverage более точного эталона. Например «магазины» поддерживает обобщённую торговую функцию, но не передаёт точный тип и период бакалеи. Таблица числаverified знаний и таблица полного покрытия — разные измерения; карточки нигде не используются вместо фактов.

## Проверка полноты mapping

Каждый доступный исходный текст получает ручной clause-by-clause список атомов, включая исключённые. Затем скрипт проверяет:

- совпадение полного видимого инвентаря claimIDs с mapping;
- непустой disposition каждого claim;
- unique occurrenceIDs и разрешимость canonicalIDs;
- ссылки на источники дляverified;
- корректность duplicate_of;
- равенство raw atomic occurrences сумме mutuallyexclusive accountingstatuses;
- пересчёт всех множеств verified/dot/experiments/union, а не ручной итог.

Скрипт не доказывает истинность источника или идеальность семантического разбора. Усечённые тексты не объявляются полными из-за техническогоPASS. Список неизвестных архивных хвостов публикуется рядом с результатом. Только полностью проверенный mapping используется для следующей сводной численной версии.
