# Насыщение фактами по тестовым фото

Живая таблица: после **каждого** продуктового прогона в неё дописывается снимок по каждому фото (`fact_saturation.py snapshot`), и страница пересобирается. Она отвечает на вопрос «нашли ли мы о доме столько же, сколько уже находили раньше». Прогон, где проверенных фактов меньше 80 % лучшего результата для этого дома, помечен **недобором** — его нужно разобрать, а не забыть.

Источники базового уровня: отчёт восстановления 10.10.2026 (15 холодных входов).
