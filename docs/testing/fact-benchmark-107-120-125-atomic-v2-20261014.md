## Правила атомизации и оценки

- Единица: субъект + один предикат + объект + временная область. Этажность, наличие цоколя, наличие мансарды, форма крыши и её покрытие считаются раздельно. Материал кирпича, полнотелость и цвет — тоже раздельно.
- При перечислении четырёх именованных объёмов записаны четыре membership-ребра; явно указанное число объёмов — отдельное свойство. Это прозрачное правило, одинаковое для output и соответствующего union.
- Значение предиката может быть интервалом: уровни 2–3 или 1875–1877 не раскладываются в два независимых события без утверждения двух разных действий. Цена/дата/автор/условие сделки — разные явно утверждённые предикаты.
- Exact coverage означает совпадение или более точное утверждение того же события/свойства. Более широкая датировка даёт partial, а не полный кредит. Generic hostel не покрывает полностью рабочий профиль и точную послевоенную привязку.
- Северный эркер 107 и крытый балкон baseline пока не доказаны эквивалентными. Они **не слиты**: новый 107-U06 добавлен в union; partial к 107-B04 остаётся для трассировки, без второго exact-кредита.
- Verified означает поддержку полным прочитанным источником для названного объекта и эпохи. Это не гарантия photo identity, подлинности source-reading цикла агента или корректности всей составной карточки.
- Qualified: конфликт дат, потеря модальности или временная область, требующая оговорки. Unverified: необходимой поддержки нужного состояния не найдено. False: источниковое противоречие, с отдельной маркировкой scope.
- Immutable baseline не переписан: прежние 7/13/25 пакетных строк сохранены в `benchmark-expansion-8cases.md`; здесь они атомизированы в 17/33/44 с полем original_bundle. Эти новые атомарные знаменатели нельзя сравнивать со старыми пакетными числителями.
- Source union = baseline + новые verified утверждения из agent output; такие строки имеют provenance discovered_from_agent. Для 125 дополнительно хранится 4 qualified-гипотезы, а verified denominator их не включает.
- Photo coverage N/A при unresolved identity. Для 107 вся поддержка архитектуры относится к ансамблю 53–61; количество ансамблевых predicates нельзя автоматически присвоить одному углу у 61. Для 125 областиH/R/N различены.
