# Панорамы и уличные фотографии: ограниченная проверка вариантов

Дата проверки: 2026-10-08. Официальные документы пяти провайдеров; новые ключи, биллинг и платные подписки не подключались. Покрытие конкретных фасадов Калининграда/Советска нельзя выводить из наличия API или карты города.

Главные исправления к приложенному тексту: общий кредит Google $200/месяц отменён с 1 марта 2025 года; сейчас у Static Street View 10 000 бесплатных событий в месяц, затем $7 за 1000 в первом платном диапазоне. Metadata бесплатны и не расходуют квоту, но требуют ключа; Street View Static требует включённого биллинга. Утверждение, что 2GIS непригоден для получения фото фасада, опровергается уже полученным и просмотренным фото Генделя, 6. Однако публичная карточка и документированный коммерческий API — разные каналы доступа.

## Тонкий adapter, без новой инфраструктуры

1. После OSM shortlist выбрать **одного** подходящего провайдера по доступным уже настроенным credentials и состоянию coverage. Не запускать пять источников автоматически на каждую фотографию.
2. Сделать дешёвую availability-проверку вокруг предполагаемой точки съёмки/видимой стороны объекта. Результат разделять на `available`, `no_coverage`, `auth_unavailable`, `transient_error`, `unsupported_export`. Пустое покрытие не смешивать с отсутствием ключа или ошибкой транспорта.
3. Из метаданных выбрать одну точку/кадр с подходящими направлением, датой и качеством. У панорамы вычислять heading из **координаты панорамы** к целевой грани здания; не переносить азимут пользовательской камеры без пересчёта. У обычного кадра проверить направление камеры. Близость точки съёмки не доказывает видимость фасада.
4. Получить **один** допустимый вид для одного кандидата, проверить реальные байты, размер и содержимое, затем визуально сопоставить фасад. При сильном совпадении остановиться; второй вид — только при конкретной неразрешённой детали. `metadata OK` и совпавший адрес не заменяют визуальную проверку.
5. Хранить provider/id/точку/дату/ракурс/source URL/access time и отрицательный результат только в пределах правил конкретного провайдера. Для Google не считать pano ID вечным: документация предупреждает об изменении ID и рекомендует сохранять исходную точку для обновления. Постоянный общий cache изображений не вводить автоматически. Метаданные, которыми провайдер разрешает пользоваться, и временные байты для сравнения разделять.
6. Один retry только для временной транспортной ошибки; при отсутствии покрытия перейти к адресной фотографии/официальной галерее. Исторические факты о здании искать после подтверждения идентичности; панорама сама по себе не источник года постройки.

Начальный бюджет adapter: один availability-вызов + одно изображение выбранного провайдера; расширение только по объяснимой причине. Для Google это может быть $0 в пределах месячного лимита, а после его исчерпания один Static-вызов в первом платном диапазоне стоит $0.007. Это расчёт по текущей опубликованной цене, не замер стоимости всего продукта.
