# Дополнительные геометрические примеры, 2026-10-08

Небольшой исследовательский пакет для уточнения поисковой стратегии Street Story. Он содержит метаданные оригиналов, три карты OSM и компактные выводы. Это не продуктовый прогон распознавания и не набор готовых ответов для runtime.

## Состав и границы

- `original-manifest.json`: 17 оригиналов — ранее использованный message102 и новые message118–133. В новой группе 16 файлов: 9 с GPS и 7 без GPS. Вместе с102 — 10 с GPS и7 без. Указаны Telegram source URL, SHA256/размер исходных байтов, размеры изображения, EXIF orientation, GPS, фокусное и даты. Фотографии и превью не включены.
- `osm/photo-120.map.png`, `osm/photo-121.map.png`, `osm/photo-122.map.png`: три карты для трёх точек съёмки. Для них использованы **два** исходных OSM snapshot:120 отдельно,121 и122 совместно используют snapshot122. Повторная загрузка OSM для121 не требовалась.
- `osm/photo-120.osm.gz`, `osm/photo-122.osm.gz`: исходные OSM XML, сжатые gzip с `mtime=0`. Соседние `*.fetch.json` содержат точный API URL/bbox, время загрузки, SHA256 и размер несжатых байтов, SHA256 gzip.
- `geometry-next-summary.json` и `geometry-next-findings.md`: компактные расчёты, наблюдения и ограничения трёх кейсов; доступны после чтения вместе с картами.
- `panorama-options.md`: ограниченная проверка пяти источников уличных изображений по официальным документам. Условия и лимиты относятся к дате проверки; покрытие конкретных фасадов не гарантируется.

Message132 имеет **отсутствующий GPS**. Для него нельзя строить карту вокруг выдуманной точки либо переносить координаты соседнего сообщения. В пакет входят его метаданные с `null`, но не карта. Это отдельная ветка поиска по видимым признакам и подтверждаемым подсказкам.

В манифесте размеры пикселей указаны до применения EXIF orientation. Даты EXIF — показания камеры, не независимо проверенная дата события. Неопределённый `DigitalZoomRatio` сообщения125 нормализован из NaN в JSON `null`. Неизвестные направление камеры и точность GPS не подменены нулём.

## Использование

Открыть карты и сопоставить их с описанием в findings. Посмотреть summary и GPS манифест можно стандартным Python: `python -m json.tool geometry-next-summary.json`. Исходный XML распаковывается командой `gzip -dk osm/photo-120.osm.gz` (аналогично для122); перед использованием следует сверить SHA256 с соответствующим fetch.json. Предыдущие исследовательские расчёты геометрии и пояснения находятся в соседнем пакете [20261008-gps-osm](../20261008-gps-osm/).

Этот пакет сохраняет компактные результаты и исходные карты; он не добавляет новый replay framework. Предыдущий пакет не изменялся. Фотографии владельца, внешние reference images, полные статьи и внутренние пути сервера отсутствуют.

Расстояния и ранги относятся к зафиксированному локальному OSM snapshot, а не ко всем зданиям города. GPS — положение камеры; ближайший footprint не обязательно является объектом в кадре. Фокусное задаёт приблизительный угол обзора, но не единственную дальность. OSM-теги и наблюдения на карте сами по себе не подтверждают идентичность здания, этажность или исторические факты. Любые именованные цели в исследовательских выводах предназначены для проверки метода, а не для подсказки рабочей модели по ID фотографии. Provider inference и платные продуктовые вызовы в этом проходе не выполнялись.
