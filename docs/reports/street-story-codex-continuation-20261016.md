- Сохранена работа Claude по полному исходному кадру и ограниченному размеру image input. Восстановление старой frozen visual операции использует её прежний transform contract; новые операции используют v2. Android показывает полный исходный кадр при отсутствии crop rectangle, сохраняя явный crop.

На 133 отсутствие этих полей воспроизвело отказ действующего guard до send. Тест теперь проходит через настоящий `ProductResearchAdapter.guard_binding`; до исправления — fail, после — pass.
